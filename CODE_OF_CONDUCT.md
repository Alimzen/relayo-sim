# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todo el mundo con respeto, critica las ideas y no a las personas, y no se toleran el acoso, los
insultos ni la publicación de datos privados de nadie.

Si ves algo que no lo cumple, avisa a quienes mantienen el proyecto por el aviso privado de GitHub (pestaña
**Security** → **Report a vulnerability**, indicando que es un asunto de conducta). Se tratará con discreción.
